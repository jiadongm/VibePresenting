# Source map

Use one row for every consequential claim, numerical result, figure or example used in the live deck.

| Slide title | Claim or visual | Source | Location | Status | Qualification for notes |
|---|---|---|---|---|---|
|  |  |  | page / figure / section | direct claim / paraphrase / interpretation |  |

## Rules

- A direct claim should be close to the source wording without becoming a long quotation.
- A paraphrase preserves the source's meaning but uses presentation language.
- An interpretation belongs to the speaker; label it as such and do not attribute it to the paper.
- Recheck a row whenever a collaborator challenges its accuracy or scope.
